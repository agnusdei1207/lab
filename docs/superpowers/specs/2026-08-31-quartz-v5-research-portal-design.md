# Quartz v5 연구 포털 전환 설계

## 목표

현재 직접 작성한 정적 연구 포털을 Quartz v5 기반 디지털 가든으로 전환한다. 공개 주소는 기존 `https://agnusdei1207.github.io/lab/`을 유지한다. 첫 화면은 복잡한 문서 목록이나 전체 그래프 대신 연구 도메인만 간결하게 보여주고, 사용자가 도메인을 선택하면 해당 분야의 연구 목록으로 이동한다.

## 정보 구조

콘텐츠의 기준 저장소는 Quartz의 `content/` 디렉터리다. 최상위 구조는 다음과 같다.

```text
content/
  index.md
  에이전트-보안/
    index.md
    red-agent/
      연구결과.md
    blue-agent/
      연구결과.md
    dynamic-honeypot-agent/
      연구결과.md
  rag-컨텍스트/
    index.md
    자율-모의해킹-에이전트-컨텍스트-연구/
      연구결과.md
  ai-모델-보호/
    index.md
    pii-privacy-module/
      연구결과.md
  플랫폼-평가/
    index.md
    autonomous-security-platform/
      연구결과.md
```

기존 이미지 파일은 각 연구 문서와 같은 폴더에 둔다. 기존 Markdown 본문과 그림 참조는 내용 손실 없이 이전하고, 내부 문서 관계는 `[[위키링크]]` 또는 일반 Markdown 내부 링크로 표현한다.

## 페이지 구성

### 메인 페이지

메인 페이지는 포털 제목과 짧은 소개, 네 개의 도메인 카드만 표시한다. 각 카드는 도메인 이름, 한 줄 설명, 포함된 연구 수를 보여준다. 최근 문서, 전체 파일 탐색기, 전역 그래프처럼 첫 화면을 복잡하게 만드는 요소는 숨긴다.

초기 도메인은 다음 네 개다.

1. 에이전트 보안
2. RAG·컨텍스트
3. AI 모델 보호
4. 플랫폼·평가

### 도메인 페이지

도메인 페이지는 해당 분야의 연구를 카드 또는 간결한 목록으로 보여준다. 각 항목에는 연구 제목, 요약, 태그를 표시한다. 새 연구는 해당 도메인 폴더에 Markdown 파일이나 폴더를 추가하고 도메인 인덱스에서 연결한다.

### 연구 페이지

연구 페이지는 본문, 목차, 태그, 연결된 문서, 백링크를 제공한다. 로컬 관계 그래프를 표시하고, 필요할 때 전체 그래프로 전환할 수 있게 한다. 검색은 모든 공개 연구 문서를 대상으로 한다.

## 메타데이터 규칙

각 연구 문서는 최소한 다음 frontmatter를 사용한다.

```yaml
---
title: 연구 제목
description: 한두 문장의 요약
tags:
  - domain/agent-security
  - topic/example
date: 2026-08-31
publish: true
---
```

검색 자료의 출처는 본문의 `## 참고문헌` 절에 링크와 확인일을 기록한다. 다른 연구와 개념적으로 연결될 때는 본문에서 해당 문서를 직접 링크해 백링크가 자동 생성되도록 한다.

## Quartz 구성

공식 `v5` 브랜치를 기준으로 설치한다. Obsidian 호환 링크 해석을 사용하고 한국어 콘텐츠가 검색 및 URL 처리에서 정상 동작하도록 확인한다. 기본 테마를 기반으로 메인과 도메인 인덱스에 필요한 최소한의 스타일만 추가한다.

활성 기능은 다음으로 제한한다.

- 전체 문서 검색
- 백링크
- 연구 페이지의 로컬 그래프 및 전체 그래프 전환
- 태그 페이지
- 목차와 링크 미리보기
- 반응형 레이아웃과 다크 모드

다크·라이트 모드는 해와 달 아이콘을 사용하는 토글 버튼으로 즉시 전환한다. 카드, 검색창, 링크 미리보기, 그래프 컨트롤 등 클릭하거나 펼쳐지는 요소는 공통 지속 시간과 easing을 사용해 자연스럽게 반응한다. 애니메이션은 정보 탐색을 방해하지 않는 짧은 전환으로 제한하고 `prefers-reduced-motion` 사용자는 움직임을 끌 수 있어야 한다.

## 배포

GitHub Actions로 Quartz를 빌드해 GitHub Pages에 배포한다. 대상은 현재 `agnusdei1207/lab` 저장소와 `/lab/` 기본 경로다. `main` 브랜치에 콘텐츠나 설정 변경이 푸시되면 사이트를 다시 빌드한다.

전환 전 기존 정적 포털 파일은 Git 기록에 남는다. 새 Quartz 빌드가 성공하고 주요 경로를 확인한 뒤에만 원격 저장소에 푸시한다.

## 검증

- Node.js 및 npm 버전이 Quartz v5 요구사항을 충족하는지 확인한다.
- 로컬 프로덕션 빌드가 오류 없이 완료되는지 확인한다.
- 메인에서 네 도메인으로 이동할 수 있는지 확인한다.
- 각 도메인에서 기대한 연구 문서가 노출되는지 확인한다.
- 기존 Markdown의 표, 코드, 한글, 이미지가 정상 렌더링되는지 확인한다.
- 문서 간 링크, 백링크, 검색, 그래프가 동작하는지 확인한다.
- GitHub Pages의 `/lab/` 하위 경로에서 정적 자산과 내부 링크가 깨지지 않는지 확인한다.

## 범위 밖

웹 기반 Markdown 편집기, 데이터베이스, 사용자 계정, 댓글, 서버 측 검색은 이번 전환에 포함하지 않는다. Markdown 작성과 출처 관리는 저장소 또는 Obsidian에서 수행한다.
