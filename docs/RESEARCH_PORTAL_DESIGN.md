# 연구 포털 설계

## 목적

흩어져 있는 AI 보안 연구 결과를 분야와 연구 단위로 분리해 보존하고, GitHub Pages에서 검색·비교할 수 있는 정적 연구 포털을 구축한다. 포털은 연구 원문을 대체하지 않고, Markdown 결과보고서를 탐색하는 색인과 요약 계층으로 동작한다.

## 핵심 원칙

1. Markdown 결과보고서와 PNG 근거 이미지를 연구의 기준 자료로 삼는다.
2. 정적 페이지에는 원문에서 확인된 수치만 표시한다.
3. 자체·통제 벤치마크 결과를 공인시험 또는 일반 성능으로 확대 해석하지 않는다.
4. 이름, 이메일, 개인 소속, 계약 및 과제 식별정보는 공개 보고서와 포털에서 제외한다.
5. 외부 CDN, 프레임워크, 패키지 설치, 빌드 과정 없이 GitHub Pages에서 동작한다.
6. 사전 지식이 없는 독자를 기준으로 연구 목적, 방법, 결과, 한계를 평이하게 설명한다.
7. 공개 화면과 결과보고서에는 원본 저장소명, 내부 파일명, 작업 경로를 나열하지 않는다.
8. 전문 용어는 처음 등장할 때 뜻을 설명하고, 버전 번호는 결과 해석에 필요한 경우에만 사용한다.

## 정보 구조

### 에이전트 연구

- RED 공격 에이전트
- BLUE 탐지·대응 에이전트
- 다이나믹 허니팟 에이전트

### RAG·컨텍스트 연구

- 다중 검색 융합 컨텍스트 구성
- 지식 전달 정확도와 전달–행동 격차

### AI 모듈 연구

- PII 탐지·변환·복구 모듈
- L2 후보 모델 비교 실험

### 플랫폼·평가 연구

- 자율 공방 시뮬레이션 플랫폼
- RED·BLUE·허니팟 KPI와 평가 체계

한 연구가 여러 분야와 관련되더라도 기준 분야는 하나만 지정하고, 나머지는 태그로 표현한다. 예를 들어 다중 검색 융합은 `RAG·컨텍스트`에 배치하고 `에이전트`, `검색`, `보안` 태그를 부여한다.

## 결과보고서 구조

각 연구의 `연구결과.md`는 다음 순서를 따른다.

1. 보고일, 연구 분야, 상태, 평가 범위
2. 한 줄 결론
3. 연구 질문
4. 접근 방법과 구조
5. 실험 또는 검증 조건
6. 핵심 결과와 지표
7. 결과 해석
8. 한계와 주의사항
9. 관련 그림

보고서에는 개인 저자 정보나 조직 홍보 문구를 넣지 않는다. 제품 가격, 계약 정보, 특허·과제 번호 등 연구 결과 이해에 필요하지 않은 사업 정보도 제외한다.

내부 구현 파일이나 원본 문서 경로를 출처 목록처럼 노출하지 않는다. 대신 독자가 이해할 수 있는 연구 배경과 측정 조건을 본문 안에서 설명한다. 검증에 필요한 내부 추적 정보는 공개 보고서와 분리한다.

## 정적 페이지

### 화면 구성

- 상단: 포털 제목, 전체 연구 수, 분야 수, 최근 갱신일
- 분야 탭: 전체 / 에이전트 / RAG·컨텍스트 / AI 모듈 / 플랫폼·평가
- 검색: 제목, 설명, 태그를 대상으로 즉시 필터링
- 연구 카드: 분야, 상태, 제목, 한 줄 결론, 대표 지표, 태그
- 상세 영역: 연구 질문, 방법, 핵심 결과, 한계, 관련 그림, Markdown 보고서 링크
- 하단: 지표 해석 원칙과 공개 범위 안내

### 데이터 흐름

```text
Markdown 결과보고서 + PNG
        ↓ 사람이 검토한 요약
정적 연구 데이터(JavaScript)
        ↓
분야 탭·검색·카드·상세 영역
```

브라우저가 Markdown을 직접 해석하게 하지 않는다. 포털에 필요한 짧은 요약과 대표 지표만 정적 데이터에 기록하고, 전체 내용은 GitHub가 렌더링하는 Markdown 원문 링크로 연결한다.

## 지표 모델

대표 지표는 연구마다 최대 네 개만 노출한다.

| 필드 | 의미 | 예시 |
|---|---|---|
| label | 짧은 지표명 | FLAG 완수율 |
| value | 화면 표시값 | 70.3% |
| context | 측정 조건 | 자체 40문항 격리 벤치마크 |
| direction | 해석 방향 | 높을수록 좋음 |

지표 카드만 보고 일반 성능으로 오해하지 않도록 측정 조건을 항상 함께 표시한다. 추정값, 계획값, 외부 검증이 불명확한 비교값은 대표 지표에서 제외하거나 본문에서 제한사항과 함께 설명한다.

## 디자인 방향

연구 노트와 실험 대시보드의 중간 인상을 사용한다. 밝은 바탕, 짙은 잉크색 본문, 분야별 절제된 강조색, 큰 숫자 중심의 지표 카드로 구성한다. 모바일에서는 카드와 지표를 한 열로 재배치하고, 키보드 탐색과 명확한 포커스 표시를 제공한다.

## 검증 기준

- 모든 탭과 검색 조합이 올바른 연구 카드만 표시한다.
- 각 카드의 대표 지표가 해당 Markdown 보고서의 수치와 일치한다.
- 모든 보고서 링크와 PNG 링크가 존재한다.
- 새 연구 자료는 Markdown과 PNG만 사용한다.
- 포털 코드에는 외부 네트워크 의존성이 없다.
- 이름, 이메일, 개인 소속, 과제·계약 식별정보가 공개 산출물에 남지 않는다.
- 공개 보고서에 원본 저장소명, 내부 파일 경로, 설명 없는 전문 약어가 남지 않는다.
- 데스크톱과 모바일 폭에서 가로 스크롤 없이 읽을 수 있다.
